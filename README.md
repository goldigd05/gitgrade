# 🚀 GitGrade - GitHub Repository Analyzer

GitGrade is a Python-based web application developed during a hackathon project.  
It analyzes GitHub repositories and provides insights using repository data and scoring mechanisms.

---

## ✨ Features

- 📂 GitHub Repository Analysis
- 📊 Repository Scoring System
- 📈 Project Evaluation
- 🖥️ Simple Web Interface
- ⚡ Python Backend Functionality

---

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- GitHub API
